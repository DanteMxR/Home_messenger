# 💬 Веб-мессенджер

Современный веб-мессенджер с функциями управления задачами, построенный на Next.js с поддержкой real-time общения для локальной сети.

## 🎯 Описание проекта

Это современный веб-мессенджер с расширенной функциональностью, который можно запустить на локальном компьютере и использовать с друзьями через LAN/IP. Приложение включает в себя:

- 💬 **Real-time чат** с поддержкой личных и групповых сообщений
- 📋 **Систему управления задачами** (Kanban-доски)
- 👤 **Админ-панель** для управления пользователями
- 📎 **Поддержку файлов и изображений**
- 🎤 **Голосовые сообщения** с записью зажатием кнопки
- 📞 **Аудио/видеозвонки** через WebRTC (личные и групповые)
- 🎨 **Современный UI** с темной/светлой темой
- 🔐 **Безопасную авторизацию** с JWT и cookies

Приложение работает на одном порту и имеет интуитивный пользовательский интерфейс.

## 🛠️ Технологический стек

### Основные технологии:
- **Next.js 15+** (App Router) — фронтенд + бэкенд (API Routes, SSR/CSR), единый порт
- **Prisma ORM** — работа с базой данных
- **SQLite** — лёгкая встроенная база данных (без дополнительной установки)
- **Socket.IO** — чат в реальном времени, сигнализация звонков
- **WebRTC** — peer-to-peer аудио/видеозвонки
- **JWT + cookies (httpOnly)** — безопасная авторизация
- **bcrypt** — хэширование паролей
- **Zod** — валидация данных
- **React Hook Form** — управление формами

### UI компоненты:
- **TailwindCSS** — базовые стили
- **shadcn/ui** — готовые красивые компоненты (формы, кнопки, модальные окна)
- **Lucide Icons** — иконки
- **Framer Motion** — анимации (готово к использованию)
- **Emoji Mart** — эмодзи picker

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd messenger-app
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-super-secret-jwt-key-change-this-in-production"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-nextauth-secret-key"
```

**⚠️ Важно:** Измените секретные ключи в продакшн-среде!

### 4. Инициализация базы данных
```bash
npx prisma migrate dev --name init
npx prisma generate
```

### 5. Запуск приложения

#### Режим разработки:
```bash
npm run dev
```

#### Продакшн сборка:
```bash
npm run build
npm run start
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 🔧 API Документация

### Аутентификация

#### POST `/api/auth/register`
Регистрация нового пользователя
```json
{
  "username": "string",
  "password": "string"
}
```

#### POST `/api/auth/login`
Вход в систему
```json
{
  "username": "string",
  "password": "string"
}
```

#### POST `/api/auth/logout`
Выход из системы

#### GET `/api/auth/me`
Получение информации о текущем пользователе

#### GET `/api/auth/socket-token`
Получение токена для Socket.IO подключения

### Пользователи

#### GET `/api/users?search=query`
Получение списка пользователей с поиском

#### GET `/api/profile`
Получение профиля текущего пользователя

#### POST `/api/avatar`
Загрузка аватара пользователя

### Сообщения

#### GET `/api/messages?receiverId=id&chatId=id`
Получение сообщений (личные или групповые)

#### POST `/api/messages`
Отправка нового сообщения

#### DELETE `/api/messages/delete`
Удаление сообщения

Редактирование сообщения

Пометить сообщения как прочитанные

Привязка сообщения к задаче

#### POST `/api/messages/clear`
Очистка истории сообщений

## 🚀 Новые функции

### 📋 Система управления задачами (Kanban)

Полнофункциональная система управления задачами с досками:

- **Создание досок** - создавайте персональные и командные доски
- **Kanban-доски** - задачи в колонках (To Do, In Progress, Done)
- **Назначение исполнителей** - назначайте задачи пользователям
- **Приоритеты** - 4 уровня приоритета (low, medium, high, urgent)
- **Сроки выполнения** - устанавливайте дедлайны
- **Чаты для задач** - автоматическое создание чатов для обсуждения задач
- **Роли пользователей** - owner, admin, member для управления доступом

### 👤 Админ-панель

Расширенные административные возможности:

- **Управление пользователями** - создание, удаление, редактирование
- **Назначение администраторов** - выдача прав администратора
- **Поиск пользователей** - фильтрация по имени
- **Статистика** - количество пользователей, задач, чатов

### 💬 Улучшенный чат

- **Редактирование сообщений** - двойной клик для редактирования своих сообщений
- **Удаление сообщений** - возможность удаления своих сообщений
- **Контекстное меню** - правый клик для действий с сообщениями
- **Групповые чаты** - создание и управление групповыми чатами
- **Управление участниками** - добавление/удаление участников
- **Ссылки на задачи** - привязка сообщений к задачам

### 🎤 Голосовые сообщения

Функция записи и отправки голосовых сообщений прямо в чате:

- **Запись** — зажмите кнопку микрофона (появляется вместо кнопки отправки, когда поле ввода пустое)
- **Отправка** — отпустите кнопку или нажмите иконку отправки
- **Отмена** — нажмите X во время записи
- **Воспроизведение** — кастомный аудиоплеер с кнопкой play/pause, прогрессом и длительностью
- **Формат** — WebM (Opus кодек), автоматическая загрузка через `/api/upload`
- Работает в личных и групповых чатах

### 📞 Аудио/Видеозвонки (WebRTC)

Полнофункциональная система звонков с peer-to-peer соединением:

#### Возможности:
- **Аудиозвонки** — нажмите иконку телефона в шапке чата
- **Видеозвонки** — нажмите иконку камеры в шапке чата
- **Личные звонки** — прямое P2P соединение между двумя пользователями
- **Групповые звонки** — mesh-топология (каждый участник соединяется с каждым)
- **Входящий звонок** — диалог с аватаром звонящего, кнопками принять (аудио/видео) и отклонить
- **Во время звонка** — переключение микрофона и камеры, таймер длительности
- **Picture-in-Picture** — локальное видео в маленьком окне поверх удалённого

#### Техническая реализация:
- **WebRTC** — браузерный API для peer-to-peer медиа-потоков
- **Socket.IO** — сигнальный сервер для обмена SDP offer/answer и ICE candidates
- **STUN серверы** — Google STUN (`stun:stun.l.google.com:19302`) для NAT traversal
- **Рингтон** — генерируется через Web Audio API

#### Компоненты:
- `CallProvider` — React Context, управляет состоянием звонков глобально
- `IncomingCallDialog` — уведомление о входящем звонке
- `CallScreen` — полноэкранный интерфейс активного звонка
- `CallControls` — кнопки управления (микрофон, камера, завершить)

> **Примечание:** Для работы за NAT (через интернет) рекомендуется настроить TURN сервер. В локальной сети STUN серверов достаточно.

### 📤 Отправка файлов и изображений

Функция позволяет пользователям отправлять файлы и изображения в чате:

1. Нажмите на значок скрепки 📎 в поле ввода сообщения
2. Выберите файл из файловой системы
3. Файл будет автоматически загружен и отправлен получателю

### Поддерживаемые типы файлов:
- Изображения: PNG, JPG, JPEG, GIF
- Документы: PDF, TXT, DOC, DOCX
- Другие файлы: любые форматы

### Отображение файлов:
- Изображения отображаются в виде предварительного просмотра прямо в чате
- Для других файлов отображается значок с названием и возможностью скачивания

### Хранение файлов:
- Все загруженные файлы сохраняются в директории `uploads/`
- Каждый файл получает уникальное имя с временной меткой
- Информация о файле сохраняется в базе данных

### Вставка изображений из буфера обмена:
- Скопируйте изображение в буфер обмена (Ctrl+C)
- Вставьте его в поле ввода сообщения с помощью Ctrl+V
- Изображение будет автоматически загружен

## 🔧 Устранение неполадок

### Проблема: Приложение не запускается
**Решение:**
1. Убедитесь, что установлены все зависимости: `npm install`
2. Проверьте файл `.env` на наличие всех необходимых переменных
3. Выполните миграции: `npx prisma migrate dev`

### Проблема: Socket.IO не подключается
**Решение:**
1. Убедитесь, что сервер запущен
2. Проверьте консоль браузера на ошибки
3. Убедитесь, что порт 3000 не занят другим приложением

### Проблема: Ошибки базы данных
**Решение:**
1. Удалите файл `dev.db` и выполните: `npx prisma migrate dev`
2. Проверьте права доступа к файлам
3. Убедитесь, что путь в `DATABASE_URL` корректен

### Проблема: Ошибки аутентификации
**Решение:**
1. Проверьте `JWT_SECRET` в файле `.env`
2. Очистите cookies браузера
3. Проверьте правильность данных для входа

## 🌐 Развертывание

### Локальная сеть (LAN)
1. Узнайте IP-адрес своего компьютера:
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ifconfig
   ```

2. Обновите `NEXTAUTH_URL` в `.env`:
   ```env
   NEXTAUTH_URL="http://YOUR_IP_ADDRESS:3000"
   ```

3. Запустите приложение:
   ```bash
   npm run build
   npm run start
   ```
4. Другие устройства в сети смогут подключиться по адресу:
   `http://YOUR_IP_ADDRESS:3000`

### Продакшен развертывание
1. Настройте переменные окружения для продакшена
2. Используйте HTTPS в продакшене
3. Настройте обратный прокси (nginx/Apache)
4. Рассмотрите использование PM2 для управления процессом
5. Настройте регулярное резервное копирование базы данных
6. Ограничьте доступ к админ-панели в продакшене

## 🔒 Переменные окружения

| Переменная | Описание | Пример |
|------------|----------|--------|
| `DATABASE_URL` | Путь к базе данных SQLite | `file:./dev.db` |
| `JWT_SECRET` | Секретный ключ для JWT токенов | `your-secret-key` |
| `NEXTAUTH_URL` | Базовый URL приложения | `http://localhost:3000` |
| `NEXTAUTH_SECRET` | Секретный ключ для NextAuth | `your-nextauth-secret` |

**⚠️ Важно:** В продакшене обязательно измените все секретные ключи и используйте HTTPS.
